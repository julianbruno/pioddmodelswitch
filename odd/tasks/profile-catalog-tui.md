# Profile catalog TUI

## Objective and accepted scope
Provide a simple editor inside Pi for viewing, editing, and creating existing-format model profiles. Model selections must come exclusively from a pre-existing JSON catalog of models available with configured Pi credentials. Export the catalog with a separate script to `config/model-catalog.json`; keep role presets in `named-profiles.json` unchanged.

## Constraints
Reuse Pi UI dialogs and the existing `/jb-odd-models` extension. Preserve strict per-agent schema, validate names and catalog selections, avoid partial/canceled saves, and register new profiles in the manifest. No credentials in exported JSON. No standalone TUI, arbitrary model entry, publishing, or implicit changes to the active profile. User explicitly requested versioning and bump: create a feature branch and work-unit Conventional Commits, bump minor version from 1.4.0 to 1.5.0 alongside the complete feature. No push or PR. User subsequently authorized installation into current Pi home using the existing backed-up installer and generation of the private local catalog.

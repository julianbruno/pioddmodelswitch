## Design and scope
Add Balance alongside existing View/Edit/Create. Capture current model/thinking at consultation, pass minimal allowlisted model metadata plus reference mapping/role descriptions and criteria to a supported registry.streamSimple call plus stream.result() (provider-neutral reasoning). Do not send conversation, source, prompt, credentials, or arbitrary SDK fields. Make provider/cost and data disclosure explicit before one call. Treat completion as untrusted data; exact managed coverage including configured judges, available identities, supported thinking, bounded rationale and strict fields required. Provider text cannot instruct tools or file writes.

Recommendation is advisory, not benchmark evidence. Balanced defaults should allocate effort according to role/task and avoid unjustified maximum reasoning everywhere. Optional quality, budget, latency, task/risk criteria may express priorities, never fabricated performance facts. Preview includes before/after assignments and rationale; save uses existing named-profile confirmation/drift/rollback boundary only. Activation remains separate shared-scope command.
